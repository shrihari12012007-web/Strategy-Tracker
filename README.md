# Strategy Tracker

Strategy Tracker is an installable Progressive Web Application (PWA) designed for tracking academic study routines, engineering milestones, and daily habits with real-time SVG progress telemetry. Built with responsive HTML5, modern vanilla JavaScript, Tailwind CSS, and Web Audio API synthesized alarm chimes, the platform features local storage persistence, categorical task segmentation (NEET, VTU CSE, Academic, Routine), a circular completion efficiency gauge, and an integrated study focus timer with zero-dependency static deployment on Vercel and Render.
